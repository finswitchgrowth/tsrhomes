# TSR Homes — Premium Three.js Web Experience

Production-ready Vite + Three.js website for **TSR Homes / True Star Realty Homes Pvt. Ltd.**

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/finswitchgrowth/tsrhomes)

Click **Deploy**, keep the Vite defaults, and deploy from `main`.

## Stack

- Node.js + Vite
- Three.js interactive hero
- Responsive premium real-estate UI
- Original TSR logo assets included as optimized base64 files
- Web3Forms lead capture with WhatsApp fallback
- JSON-LD `RealEstateAgent` structured data
- Canonical, Open Graph, robots.txt and XML sitemap
- GitHub Actions multi-agent quality gates

## Web3Forms

The form is already wired to `https://api.web3forms.com/submit`.

Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html` with the access key generated by Web3Forms. Until that is done, the form automatically falls back to WhatsApp so a lead is not lost.
