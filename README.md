# TSR Homes — Premium Web Experience

A lightweight Vite + Three.js real-estate landing experience for TSR Homes.

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/finswitchgrowth/tsrhomes)

Click **Deploy** → keep the defaults → **Deploy**.

## Stack

- Vite + Node.js
- Three.js
- Responsive CSS
- WhatsApp lead handoff
- GitHub Actions quality gates

## Automated cross-check agents

1. Architecture/dependency + production build
2. UI/static requirements
3. Security/deploy hygiene
4. Final gate aggregation

The site intentionally keeps the runtime simple: one main page, no database, no secrets, and no backend required for the initial launch.
